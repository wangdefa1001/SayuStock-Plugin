# 早柚股票 SayuStock · TRSS-Yunzai 版

把 [KimigaiiWuyi/SayuStock](https://github.com/KimigaiiWuyi/SayuStock)（原 gsuid_core / Python 插件）
移植到 **TRSS-Yunzai** 的版本。

原版是 Python + gsuid_core，跑不到 Node.js 的 Yunzai 上，所以这里是**用 JS 重写**：
行情数据层、SVG 绘图层、指令层全部重新实现，只保留原版的数据口径（东财 secid / 分时 / K线 / 涨跌分布字段含义）
和交互习惯（指令名、别名、多标的空格分隔、板块自动展开）。

- 运行环境：TRSS-Yunzai（Yunzai 3.x）、Node ≥ 18
- 额外依赖：**无**。不装 npm 包、不装 Python、不装浏览器插件之外的任何东西
- 出图：复用 Yunzai 自带的 `lib/renderer`（puppeteer），图表是插件自己生成的 SVG，不依赖 Chart.js / CDN
- 许可：GPL-3.0（原项目同协议，本移植版同样遵循）

## 一、安装

```bash
cd Yunzai/plugins
git clone https://github.com/<你的用户名>/SayuStock-Plugin.git SayuStock-Plugin
```

或用文件管理器把整个 `SayuStock-Plugin/` 目录放进 `Yunzai/plugins/`，然后 `pnpm i` 或直接重启 Yunzai
（本插件没有任何 npm 依赖，不装也不会报缺包）。

启动日志里出现 `加载插件 [SayuStock/index.js][早柚股票-大盘]` 之类的行即为加载成功。

> **中文字体**：图片由 Chromium 渲染，宿主机需要中文字体，否则会显示方框。
> Debian/Ubuntu：`apt install -y fonts-noto-cjk`；Arch：`pacman -S noto-fonts-cjk`。
> 手机 chroot 环境里如果装不了字体，可以把宿主的字体目录 bind 进容器。

## 二、指令

指令前可加 `#`，也可不加。多条标的用空格分隔，中文逗号也会被当作分隔符。

### 大盘行情

| 指令 | 说明 | 例子 |
| --- | --- | --- |
| `大盘概览` / `大盘` | 主要指数、涨跌分布、两市成交额、领涨领跌行业 | `大盘概览` |
| `大盘云图` | 全A总市值前 120 只热力图，面积=市值、颜色=涨跌 | `大盘云图` |
| `行业云图 [名称]` | 行业板块热力图，不带名称则看全部行业板块 | `行业云图 半导体` |
| `概念云图 [名称]` | 概念板块热力图 | `概念云图 白酒` |
| `全天候` | 全球股市 / 大宗商品 / 外汇债券 / 加密货币 | `全天候` |

### 个股

| 指令 | 说明 | 例子 |
| --- | --- | --- |
| `个股 [标的]` | 当日分时图 | `个股 证券ETF` |
| `个股 五日 [标的]` | 五日分时（是分时线，不是K线） | `个股 五日 贵州茅台` |
| `个股 日k [标的]` | 日K + MA5/10/20/60 + 成交量 | `个股 日k 510300` |
| `个股 周k / 月k / 季k / 年k [标的]` | 对应周期K线 | `个股 周k 白酒ETF` |
| `个股 [板块名]` | 板块自动展开为成交额前 13 只成分股的分时网格 | `个股 白酒` |
| `个股 A B C` | 多只标的迷你分时网格 | `个股 510300 512880 600519` |
| `我的个股` | 自选前 5 只当日分时 | `我的个股` |

### 对比

| 指令 | 说明 | 例子 |
| --- | --- | --- |
| `对比个股 [标的...]` | 归一化涨跌幅对比，默认最近一年，最多 12 只 | `对比个股 510300 512880` |
| `对比个股 年初至今 ...` | 支持 `年初至今` / `最近一月` / `最近三月` / `最近一年` / `最近两年` | `对比个股 年初至今 白酒ETF 医药ETF` |
| `对比个股 2024.01.01~2024.12.31 ...` | 自定义区间 | `对比个股 2024.01.01~2024.06.30 600519` |

不带标的时，自动拿你的自选列表来比。

### 自选

| 指令 | 说明 |
| --- | --- |
| `添加自选 600519 贵州茅台 白酒ETF` | 支持股票/ETF/指数/板块/场外基金 |
| `删除自选 600519` | 与自选里的标的匹配后删除 |
| `清空自选` → `确认清空自选` | 二次确认，60 秒内有效 |
| `我的自选` | 表格：现价/涨跌幅/涨跌额/换手/成交额/分时缩略 |

### 新闻

| 指令 | 说明 |
| --- | --- |
| `订阅雪球新闻` | 群内每 5 分钟自动推送快讯 |
| `取消订阅雪球新闻` | 关闭本群推送 |
| `财经快讯 [条数]` | 立即查询，默认 8 条，最多 20 条 |

### 其他

`股票帮助` / `早柚股票帮助` —— 帮助图。

## 三、配置

首次运行后会自动生成 `SayuStock-Plugin/data/config.json`：

```json
{
  "image": true,
  "maxMultiStock": 5,
  "maxCompare": 12,
  "cloudmapStocks": 120,
  "maxWatch": 30,
  "news": { "interval": 5, "pages": 3, "push": true }
}
```

| 字段 | 作用 |
| --- | --- |
| `image` | 设为 `false` 时只回文字（没有 puppeteer 环境的兜底开关） |
| `maxMultiStock` | 「个股」一次最多画几只迷你分时 |
| `maxCompare` | 「对比个股」一次最多几条线 |
| `cloudmapStocks` | 大盘云图取样只数，越大方块越碎 |
| `maxWatch` | 每人自选上限 |
| `news.push` | 关掉后不再定时推送（订阅关系保留） |

数据文件都在 `SayuStock-Plugin/data/`，可直接备份或迁移：

- `config.json` 配置
- `watchlist.json` 自选（按 QQ 号存 secid）
- `news_sub.json` 群订阅关系
- `news_seen.json` 快讯推送游标（防重启重复推）

## 四、数据源与稳定性

行情全部来自东方财富，不同指令走不同接口，并在主源失效时自动降级：

| 数据 | 主源 | 兜底 |
| --- | --- | --- |
| 大盘云图 | `quote.eastmoney.com/stockhotmap`（一次返全市场 5000+ 只，不翻页） | `push2/api/qt/clist` 翻页 |
| 行业云图（带名称） | 本地行业表（5921 只，含三级行业）+ 热力图行情 | 东财板块成分接口 |
| 行业云图（不带名称） | 热力图按一级行业市值聚合 | 东财行业板块列表 |
| 概念云图 | 东财板块成分接口 | 命中本地行业表时用本地兜底 |
| 指数快照 | `push2/api/qt/ulist.np`（批量） | 逐只 `stock/get` |
| 分时 / K线 | `push2his` trends2 / kline | — |
| 涨跌分布 | `quotederivates/updowndistribution` | — |
| 名称搜索 | `searchapi/suggest` | 本地股票名字典 |

另外做了三件降低被封概率的事：

1. **TTL 缓存**：快照 5s、分时 20~60s、K线 5min、板块列表 60s、名称搜索 30min
2. **并发闸门**：同时最多 4 个上游请求，避免一次性打十几个
3. **主机熔断**：某个接口刚失败过，20 秒内直接失败并提示，不会让每个指令都卡满重试时间

> 东财对高频/异常流量会临时断开连接（表现为 `fetch failed`），一般几分钟到十几分钟自动恢复。
> 正常群聊使用频率不会触发；如果你在调试期连续压测，可能会短暂看到「接口刚失败过」的提示。

## 五、与原版的差异（重要）

原版是 42,000 行 Python、366 个文件，包含 8 套行情源适配器、模拟盘策略引擎、AI 工具链、宏观分析模块。
**本次移植聚焦行情与看盘主链路**，以下功能没有搬：

| 原版功能 | 本版状态 | 说明 |
| --- | --- | --- |
| 大盘概览 / 云图 / 个股分时 / K线 / 对比 / 自选 / 快讯 | ✅ 已实现 | 见上表 |
| 全天候 | ✅ 已实现 | 加密板块走 OKX，网络不通时该分组自动省略 |
| IPO 日历 | ❌ 未实现 | 需要东财 datacenter 多张报表联查 |
| 基金持仓 / 持仓分布 | ❌ 未实现 | 场外基金净值对比也未接入 |
| 技术分析 / 股票卡片 / 自动选股 / 组合体检 | ❌ 未实现 | 指标数学已内置（MA/EMA/BOLL/MACD/KDJ/RSI），但没接指令 |
| 模拟盘（建盘/策略/撮合/广播） | ❌ 未实现 | 原版一整套 SQLModel + 策略引擎，工作量最大的一块 |
| AI 模型预测（Kronos）、AI 工具链 | ❌ 未实现 | 依赖外部模型服务 |
| 雪球新闻 | ⚠️ 换了源 | 雪球匿名接口需要现抓 Cookie（原版靠 Playwright），本版改用**东财 7x24 快讯**，指令名保留 |
| 多行情源（新浪/腾讯/同花顺/天天基金/AAStocks/纳斯达克） | ❌ 只保留东财 | 原版是「东财主 + 多源兜底」，本版单源；东财挂了就取不到 |
| 场外基金 K 线/净值 | ❌ 未实现 | 会明确提示「场外基金没有K线」 |

如果你需要模拟盘或技术分析这类重功能，建议**单独开一轮需求**：这些可以从 `model/indicators.js`
和现有数据层往上加，不需要重写底层。

## 六、排错

| 现象 | 原因 / 处理 |
| --- | --- |
| 图片里中文是方框 | 宿主缺中文字体，装 `fonts-noto-cjk` |
| 一直回文字而不是图 | 没检测到渲染器，看启动日志有没有 `渲染后端 puppeteer 加载成功`；或 `data/config.json` 里 `image` 被设成 false |
| `❌ 请求失败 ...` / `接口刚失败过` | 东财限流或断连，等几分钟再试；本机排查用 `curl -I https://push2.eastmoney.com` |
| `❌ 指数行情为空` | 批量与逐只快照都没取到，通常就是被限流了 |
| `❌ 没找到「xxx」` | 名称搜索没命中，换六位代码或更完整的名称试试 |
| 云图方块全是碎条 | 调小 `cloudmapStocks`（比如 80）；板块云图已默认只画市值前 120 只 |
| 快讯不推 | 检查 `data/news_sub.json` 有没有该群、`news.push` 是否为 true；部分适配器不支持主动发群消息 |

## 七、目录结构

```
SayuStock-Plugin/
├── index.js                # 插件入口，聚合 apps
├── package.json
├── render.js               # 出图入口 + 全局样式表 + 数字格式化
├── apps/                   # 指令层（正则 → 取数 → 出图 → 回话）
│   ├── market.js           # 大盘概览 / 云图 / 全天候
│   ├── stock.js            # 个股分时 / K线 / 我的个股
│   ├── compare.js          # 对比个股
│   ├── watchlist.js        # 自选增删查
│   ├── news.js             # 快讯订阅与推送
│   └── help.js             # 帮助
├── model/                  # 数据层
│   ├── em.js               # 东财接口（快照/分时/K线/板块/涨跌分布/搜索/OKX）
│   ├── symbol.js           # 输入解析：名称/代码/拼音 → secid；板块解析
│   ├── market.js           # 业务编排
│   ├── indicators.js       # MA/EMA/BOLL/MACD/KDJ/RSI + 技术面打分
│   ├── store.js            # 配置 / 自选 / 订阅 存储
│   └── news.js             # 快讯拉取与游标
├── components/
│   ├── charts.js           # SVG：分时/K线/对比/云图/迷你走势
│   ├── cards.js            # 卡片组装
│   └── reply.js            # 出图回话与异常兜底
├── resources/card.html     # 渲染模板（art-template，只注入 css 与 body）
└── data/                   # 运行时生成
```
